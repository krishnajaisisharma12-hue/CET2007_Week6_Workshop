# CET2007 Week 6 Workshop - IT Helpdesk System

Simple C# Console Application (.NET Framework) demonstrating **Generics** and **Collections** (`List<T>`, `Dictionary<TKey, TValue>`, `Queue<T>`, `Stack<T>`).

## Exercises Included
- **Exercise 0:** Visual Studio project setup, XML documentation (`///`), and GitHub README.
- **Exercise 1:** `Notification`, `AssignmentRecord`, `ResolutionRecord`, and generic `HelpdeskMsgHandler<T>`.
- **Exercise 2:** `Ticket` and `Helpdesk` using `List<Ticket>` and `Dictionary<string, Ticket>` with duplicate ID checks.
- **Exercise 3:** Ticket assignment and FIFO waiting list using `Queue<string>`.
- **Exercise 4:** Undo last assignment using `Stack<Ticket>`, ticket resolution with waiting queue notification, and an interactive console menu.

## How to Run
1. Open `CET2007_Week6_Workshop.sln` in Visual Studio.
2. Press **F5** (or click **Start**) to run the console menu.
